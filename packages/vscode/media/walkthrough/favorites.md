## Favorite and Organize

Right-click any entry in the sidebar to:

- **Toggle Favorite** — Star commands for the Favorites panel
- **Copy Slash Command** — Copy the `/command` to clipboard
- **Copy Content** — Copy the full command content
- **Open Source File** — Jump to the markdown source
- **Insert to Terminal** — Send the command to your active terminal

Your favorites and usage counts persist across sessions.
